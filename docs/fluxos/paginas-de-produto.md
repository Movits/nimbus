# Fluxo: páginas de produto

Pendência aberta do projeto. Cada página precisa de material, modelagem, tabela
de medidas, prazo POD, política e impacto social.

**Medidas:** use [`../verdades/medidas-pecas.md`](../verdades/medidas-pecas.md).
O Blusão Moletom tem comprimento **estimado**; se a página for publicar a tabela
dele, confirme antes com a YouDraw.

**Impacto social:** 10% do lucro de cada pedido para um projeto social escolhido
pelo cliente, após custos e o prazo de arrependimento. Repasse mensal, com
registro e comprovação. Não prometa prazo ou percentual diferente disso.

**Tom:** curto, humano, específico e reverente. Sem texto genérico ou exagerado.
**Não usar travessão em copy pública.**

**Nunca expor** CPF, endereço, senha, cookie, token ou dado de cliente — o
repositório é público.
